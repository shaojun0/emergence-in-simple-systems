# 05 · 反直觉发现与开放问题

本文件是仓库的**任务清单**。每条开放问题都配了可执行的否证协议 —— 我们欢迎的是
"这个实验能杀死哪条判据"，而不是"这个想法很深刻"。

---

## 第一部分 · 实验一的四个反直觉发现

### 发现 1 · 算子空间里有长程通路 ≠ 模型会用长程通路

`spectral` 的参数化允许任意全局 all-to-all 卷积（385 频率 × 96 通道），
但训练后直接读核：

| lag | 能量占比 |
|---|---|
| 0（恒等） | **0.928** |
| ±1 | 0.053 |
| ±2 | 0.011 |
| >8 | **0.006** |

**模型自发收敛到局部模板**（等价于一个 CA 邻域规则），且能力上限只到双向 ±2 的
计数模型（1.230 vs 1.200）。

**教训**：判据 3（相互作用丰富）是**参数化的性质**，判据 6（任务需要长程）
是**问题的性质**。把前者给足并不会自动让后者成立。

### 发现 2 · 可训练性是第二道闸门，而且比表达能力更常成为瓶颈

同一个骨架、同一个优化器（纯 SGD），只换混合层：

| 混合层 | 初始化 | 行为 |
|---|---|---|
| 谱滤波 | `H = 1`（恒等） | lr 0.05→1.2 **全程稳定单调下降** |
| 自注意力 | Glorot | **双峰**：lr0.8 先到 2.47 再崩到 3.46（两种子皆崩）；lr0.2 或输出零初始化才正常 |

**教训**：文献里"某算子能表达 X"的论断，在缺少 Adam 时可能完全无法兑现。
判据 5 应该和表达能力并列为一等公民。

### 发现 3 · 崩溃有一种干净的定量特征：退化成 unigram

注意力崩塌时，验证准确率恰好落在 **0.1609**（unigram 基线 0.1460），
验证损失 ≈ 3.31（H(unigram) = 3.348）。

**教训**：混合层失效 ⟹ 模型退化为**逐位置独立分类器**。
这个特征可以作为通用的诊断指标：**准确率 ≈ 最高频类别频率**，就是混合层死了。

### 发现 4 · 从 FNO 借来的"分辨率无关性"在语言上不成立

在 T=96 训练、零样本外推：

| 长度 | spectral | fnet |
|---|---|---|
| 96 | 1.268 / 0.642 | 2.344 / 0.347 |
| 192 | 3.516 / 0.220 | 3.777 / 0.133 |
| 384 | 4.081 / 0.174 | 4.218 / 0.096 |
| 768 | 3.943 / 0.163 | 5.147 / 0.103 |

**教训**：谱参数化的"分辨率无关"是**算子在函数空间上的性质**，
不是"训练好的网络能外推长度"的保证。这两件事被反复混淆。

## 第二部分 · 开放问题与否证协议

成本按本机（8 核 CPU，纯 NumPy）估算。

| ID | 问题 | 一次实验的否证条件 | 成本 |
|---|---|---|---|
| Q1 | 任务真的要求长程时，学到的核会变长程吗？ | 核仍停在 lag≤2 且性能不高于局部基线 | ~2h |
| Q2 | 局部模板（CA/stencil）能否追平全局谱算子？ | stencil 明显差于 spectral ⟹ 长程通路确有价值 | ~2h |
| Q3 | 谱算子 + 内容依赖自门控，能否拿回注意力的能力且保持稳定？ | 门控后仍不稳定或仍不优于注意力 | ~3h |
| Q4 | 模加法任务上，傅里叶骨架是否"瞬时 grokking"？ | 不出现快速相变，或出现但内部无傅里叶结构 | ~1h |
| Q5 | 多尺度（小波 / MERA 式）是否优于单尺度谱混合？ | 无显著差异 ⟹ 多尺度先验对该任务无用 | ~3h |
| Q6 | 放大 N/d/L 是否出现定性相变（涌现的操作化定义）？ | loss 平滑外推、无拐点 | ~天 |
| Q7 | 注意力在纯 SGD 下真的**不可能**稳定，还是只是 lr 没调对？ | 完整长程 lr 网格下存在稳定且最优的 lr | ~4h |

### Q1（最重要）· 长程需求下的核结构

- **假设**：如果数据要求长程依赖，`spectral` 学到的核会从局部扩展为长程。
- **协议**：构造合成任务，其解必须依赖远距离信息，例如
  (a) 从第 k=64 位之前复制 token（copy/induction 任务）；
  (b) 括号匹配（需要跨距配对）；
  (c) 序列反转 / 排序。
  训练同规模 spectral 模型，然后用 `spectral_bert.py` 的 `mixer_analysis`
  直接读核的 lag 分布。
- **否证条件**：任务可解（准确率显著高于随机基线）**但核仍停在 lag ≤ 2**
  → 说明长程信息是由别的通路（如残差 + LN 的堆叠）传递的，而非谱混合；
  或者任务不可解 **且**核不扩展 → 说明该算子无法实现被要求的长程相互作用。
- **价值**：这是唯一能直接把判据 3 和判据 6 分开的实验。

### Q2 · 局部模板的性价比

- **假设**（由发现 1 直接推出）：既然学到的核是局部的，那么**直接用局部 stencil
  当混合层**应该能追平 spectral，而参数更少、复杂度更低。
- **协议**：把混合层换成 `y = Σ_{|d|≤k} w_d · shift_d(x)`（深度可分离、逐通道、
  可学习、零初始化附近），k=1..2，其余完全不变，跑同样的 3000 步。
- **否证条件**：stencil 显著差于 spectral → 说明"核看起来局部"是**平均假象**，
  真正起作用的是少数全局混合通道（见实验一 §4.5：层 0 有一条通道 96% 是跨位置混合）。
- **备注**：这个实验会直接检验"通道分工"假设是否是真机制。

### Q3 · 内容依赖路由（补上谱算子最大的短板）

- **假设**：纯谱混合是**数据无关**的固定卷积，缺少注意力"按内容路由"的能力；
  加一个由信号自身计算的频域门控可以补上，且不引入注意力的不稳定。
- **协议**：`y = IFFT(FFT(x) ⊙ σ(W · FFT(x)))`（自门控）或 AFNO 式的
  块对角 + 软阈值。与 spectral / attn / attn+wo_zero 四臂对照。
- **否证条件**：门控版在稳定性与最终指标上都不优于 attn+wo_zero。

### Q4 · 模加法上的"瞬时 grokking"

- **假设**：模加法是傅里叶结构主导的（grokking 文献里 Transformer 内部自发形成
  傅里叶电路），那么把傅里叶作为**骨架**而非涌现产物，应该让 grokking 几乎瞬时发生。
- **协议**：(a mod p + b mod p) mod p，p=113，50% 训练样本；对照
  Transformer 基线，记录测试准确率的相变步数；对谱模型做频率消融，
  验证它确实用了傅里叶表示。
- **否证条件**：不出现快速相变，或相变出现但频率消融不掉性能
  → 说明"傅里叶骨架"没有起到预期作用。
- **价值**：这是唯一一个**成本低且大概率能拿到正面结果**的实验。

### Q5 · 多尺度 / 张量网络

- **假设**：实验一的核是单尺度的局部的；引入多尺度结构（小波金字塔、
  或 MERA 式的 χ 键维）可能以更少的参数换到更长的有效感受野。
- **协议**：用固定小波基替换傅里叶基（同样的可学习对角缩放），以及
  用两级/三级分辨率金字塔；对比同参数预算下的 val loss。
- **否证条件**：无显著差异 → 多尺度先验对该任务无价值。

### Q6 · 规模（判据 2 的正面对撞）

- **假设**：按 [`00-hypothesis.md`](00-hypothesis.md) 的操作化定义，
  涌现表现为**定性相变**而非平滑提升。
- **协议**：扫 N ∈ {96, 192, 384}、d ∈ {64, 96, 192, 384}、L ∈ {2,3,6}，
  在 Q1 的长程任务上画 loss-规模曲线，检查是否有拐点。
- **否证条件**：曲线平滑可外推，无拐点 → 在该任务族上不存在可观测的涌现相变。
- **备注**：这是判据 2 唯一诚实的检验方式，也是本仓库最贵的实验。

### Q7 · 给注意力一个公平的机会

- **背景**：实验一里每个 arm 的 lr 只在 **400 步**上扫过，这对注意力不公平
  （它的长程最优 lr 可能不同）。
- **协议**：在 3000 步尺度上对 attn 做完整 lr 网格 {0.05, 0.1, 0.2, 0.4, 0.8} × 3 seed，
  记录"稳定窗口"的宽度，与 spectral 的窗口对比。
- **否证条件**：若存在一个 lr 使注意力稳定且达到或超过 spectral
  → 那么"谱算子更稳健"的结论要弱化为"谱算子的稳定窗口更宽"（量上的差别）。

## 第三部分 · 已知的负面结果登记（防止重复踩坑）

1. **纯傅里叶算子复合会坍缩**：`F⁴ = I`，无深度。必须插非线性。
2. **lr 1.6 时 spectral 发散**（train loss 6.52）；**lr 1.2 的 seed 2 早期发散过**
   （step 500 val = 16.99）后靠梯度裁剪恢复。谱算子也不是无条件稳定。
3. **`wo_zero`（注意力输出零初始化）能修好稳定性**，但没有修好"起步慢"
   —— 它在 step 250 仍贴 unigram。
4. **FNet 式零参数混合稳定但天花板低**（6000 步 2.25 vs 可学习滤波器的 1.23）。
5. **长度外推在两个 arm 上都失败**（见发现 4）。
6. **计数基线的天花板**：双向 ±4 / ±6 的 n-gram 因数据稀疏退化到 3.11 / 3.99，
   所以本语料无法构造更大的"局部 oracle"来对比 —— 若要检验长程价值，
   必须用合成任务（Q1）而不是继续加 n-gram 阶数。
