# 02 · 候选算子族清单

本文件回答："除了矩阵、图、傅里叶，还有哪些算子可能满足 [`00-hypothesis.md`](00-hypothesis.md)
里的六条判据？"

---

## 1. 先纠正一个隐含前提：你列的三个其实是同一族

- **矩阵** = 任意线性算子（最一般形式）
- **图** = 稀疏 / 带局部性先验的矩阵
- **傅里叶** = 循环矩阵的对角化基（卷积定理：时域卷积 ↔ 频域逐点乘）

所以它们不是三个并列的选项，而是**同一个线性算子族在不同结构先验下的取值**。
图傅里叶变换就是"图 × 傅里叶"的合体。

**真正决定性质的，是你烘焙进去的结构先验**：稀疏性、平移等变性、
多尺度结构、对称群。这也解释了为什么"纯线性算子"无论选哪一族都会坍缩
（判据 4）：换基不改变线性性。

---

## 2. 八个候选族

| 族 | 原语 | 每步复杂度 | 相互作用范围 | 非线性从哪来 | 实证水平 |
|---|---|---|---|---|---|
| 多尺度 / 时频 | 小波、STFT、球谐 | O(N) | 局部→全局分层 | 系数阈值化 | 信号/医学成熟，语言未通 |
| 结构矩阵 / 快速变换 | 蝶形、Monarch、Hadamard | O(N log N) | 全对全 | 逐点非线性 | 小规模有实证 |
| **张量网络** | MPS/PEPS、**MERA** | O(N·χ³) | **由键维 χ 连续可调** | 张量收缩本身非线性 | 物理成熟，ML 小众 |
| **局部模板 / 元胞自动机** | CA、Lenia、stencil、PDE | O(N·k) | 局部（用深度换范围） | 规则本身 | 合成任务有实证 |
| 状态空间 / 长卷积 | S4、Mamba、Hyena | O(N log N) | 全局（可因果） | 门控 | 语言上有实证 |
| 代数 / 对称 | 群卷积、李群、Clifford、**热带半环** | 视群而定 | 由对称群决定 | 群作用 | 专门领域 |
| 概率 / 能量 / 物理 | Ising、Hopfield、耦合振子、量子酉电路 | 视模型而定 | 全对全（平均场） | 采样/退火 | 理论上限高 |
| 条件计算 / 路由 | MoE、LSH、检索、排序网络 | O(N log N)~O(N) | **数据依赖**的稀疏全对全 | 路由+专家 | LLM 里已大规模在用 |

### 2.1 多尺度 / 时频族（傅里叶的直系亲属）

小波（Haar / Daubechies）、STFT / Gabor、金字塔、分数阶傅里叶、啁啾变换、
球谐（3D 等变）、图傅里叶、Laplace / Mellin 变换。

- **为什么满足判据 3**：小波基同时具备局部性与频谱选择性，比纯傅里叶多一个尺度轴。
- **为什么可能更好**：实验一发现模型自发收敛到**局部**核——小波基的局部性先验
  与这个实测行为一致，可能比全局傅里叶基更匹配。
- **代表**：Mallat 的散射网络（固定小波 + 模非线性 + 平均，零学习）。

### 2.2 结构矩阵 / 快速变换族（矩阵的稀疏因子化）

蝶形矩阵（butterfly）、Monarch / Kaleidoscope、Hadamard / Walsh、循环 / Toeplitz、
稀疏随机投影、随机傅里叶特征（Bochner 定理）。

- **关键事实**：**FFT 算法本身就是一个 log N 层深的蝶形神经网络**，twiddle 因子
  （单位根）就是它的权重。把蝶形权重设为可学习，就得到"可学习的 FFT"，
  能在 FFT、卷积、Hadamard 之间连续插值。
- **满足判据 1、2**：O(N log N)，且单元是固定的稀疏结构，参数随 log N 增长。

### 2.3 张量网络族 —— 本仓库认为**最被低估**的一支

MPS / MPO（张量列）、PEPS、**MERA**、TT / CP 分解。

- **为什么最值得关注**：**键维 χ 直接就是"相互作用丰富度"的独立连续旋钮**，
  而 N（格点数）和 χ 可以分开放大 —— 这是唯一一个把判据 2 和判据 3
  做成两个正交旋钮的框架。其他族里"更丰富的相互作用"通常意味着更贵的稠密计算。
- **MERA 天然是多尺度的**，且在物理上被认为是重整化群的离散实现，
  与深度网络的层间结构有对应关系（见 [`01-literature-verification.md`](01-literature-verification.md) §B）。
- **与傅里叶的关系**：平移不变态的 MPS 谱与频率模态有对偶结构，两族不是对立的。

### 2.4 局部模板 / 元胞自动机族 —— 最字面地实现原命题

元胞自动机（Rule 110 图灵完备）、Lenia（连续 CA）、Growing Neural CA、
有限差分 stencil、反应扩散 / PDE 演化、扩散模型、Neural ODE。

- **判据 1 满分**：规则极简、天然平移等变、**深度 = 时间步**（不需要额外设计层）。
- **判据 3 的解决方式**：单步只有局部作用，但**时间步数可以换取感受野**
  （t 步 → 感受野 ±t·k）。这是"用深度换相互作用范围"的范式。
- **实验一的相关发现**：我们训练出的谱混合核**自发收敛到了局部模板**
  （lag0 93%、±1 5.3%、>8 仅 0.6%）。也就是说模型自己走到了这一族。
  这提示：**在数据只要求局部统计时，CA 可能是性价比最高的实现方式。**

### 2.5 状态空间 / 长卷积族

S4、Mamba、Hyena。

- **与傅里叶同源**：对角化状态空间模型在数学上就是一个频域算子；
  S4 用 FFT 实现长卷积核。所以这一族可以视作**傅里叶族加了因果性**。

### 2.6 代数 / 对称族

群等变卷积（G-CNN）、李群 / 规范等变、Clifford / 超复数、
**热带半环（max-plus）**、有限域 / 模运算、张量积表示。

- **核心思想**：把对称性/绑定操作**做成算子**，而不是让模型学出来。
- **热带半环**把"动态规划 / 最短路"写成算子（max-plus 矩阵乘），
  对应 [Tropical Attention](https://ar5iv.labs.arxiv.org/html/2505.17190)。
- **有限域上的模运算**值得单独列：grokking 研究里真正观测到"涌现"的地方
  就是模加法，而它是傅里叶结构主导的 —— 这是判据 4（非线性生成新频率）
  在算法任务上的直接体现。

### 2.7 概率 / 能量 / 物理族

Ising / 自旋玻璃、现代 Hopfield、玻尔兹曼机、耦合振子（Kuramoto）、
随机游走 / 扩散、参数化量子电路（酉算子）。

- **为什么与"涌现"天然相关**：临界性、共振、退火都是物理里已有的涌现机制。
- **现代 Hopfield 证明了注意力等价于一次能量下降的检索**
  （[Ramsauer 等, ICLR 2021](https://mlanthology.org/iclr/2021/ramsauer2021iclr-hopfield/)），
  这把本族与矩阵族接上了。
- **耦合振子**对应本仓库早期讨论里的假设："注意力 = 可学习的共振"。

### 2.8 条件计算 / 路由族

MoE、稀疏注意力、哈希 / LSH、检索增强（kNN / 关联记忆）、排序网络、动态规划。

- **这一族回答了一个关键缺陷**：实验一指出，纯谱算子的混合是**数据无关**的
  （频域滤波 = 固定卷积），缺少注意力真正的杀手锏——**按内容路由**。
  路由族用"数据依赖的稀疏全对全"补上这一点，且已在 LLM 规模验证。

### 2.9 物理基底（跨族的实现层）

光学衍射网络（D²NN，透镜在焦平面以光速物理执行傅里叶变换）、波 / 声 / 机械计算、
模拟电路。

- **判据 1、3 天然满足**：波传播本身就是全对全相互作用，零功耗。
- **与傅里叶族的接口**：菲涅耳/夫琅禾费衍射 ≈ 分数阶傅里叶变换，
  所以"衍射 + 相位层"的级联就是物理版的谱混合网络。

## 3. 按六条判据打分

| 族 | 1 简单 | 2 可扩展 | 3 丰富 | 4 非线性 | 5 可训练 | 6 任务需要 | 已证智能 |
|---|---|---|---|---|---|---|---|
| 矩阵（稠密/注意力） | ✗ O(N²) | ✓ | ✓ | ✓ | △ 双峰（实验一） | ✓（LLM） | **✓ 已达成** |
| 图 / 消息传递 | ✓ | ✓ | △ 依图结构 | ✓ | ✓ | ✓ | ✓ 专门领域 |
| 傅里叶 / 谱 | ✓ | ✓ | ✓（但实测不用） | 需外接 | **✓ 最稳（实验一）** | ✗ 实验一未满足 | ✗ 仅 n-gram 级 |
| 多尺度 / 小波 | ✓ | ✓ | ✓ | 需外接 | 待测 | 待测 | ✗ |
| 蝶形 / Monarch | ✓ | ✓ | ✓ | 需外接 | 待测 | 待测 | ✗ |
| 张量网络 / MERA | ✓ | ✓（χ 可控） | ✓（χ 可调） | 收缩 | 待测 | 待测 | ✗ |
| 元胞自动机 | **✓✓** | ✓ | △（靠深度换） | ✓ | 待测 | 待测 | ✗ |
| SSM / 长卷积 | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ 语言有实证 |
| 代数 / 对称 | ✓ | ✓ | 依群 | ✓ | 待测 | 待测 | ✗ |
| 概率 / 能量 | △ | △ | ✓ | ✓ | △ | 待测 | ✗ |
| 路由 / MoE | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ | **✓ LLM 规模** |

**读表结论**：目前真正在"通用能力"上达到智能水平的只有**矩阵族**和它的
变体（路由/MoE、SSM）；其余各族的实证都还停在玩具规模或纯理论。
所以"还有啥"的诚实回答是：**候选很多，但经验门槛极高。**

## 4. 选型时的三条实用建议（来自实验一的教训）

1. **优先选能恒等初始化的算子**。`H = 1` 让谱混合开局即恒等、全程稳定；
   注意力用 Glorot 初始化则在纯 SGD 下双峰崩溃。判据 5 不是理论细节。
2. **检查"丰富性"是否真的被使用**。训练后直接读算子矩阵/核，量化
   恒等成分 vs 长程成分（实验一的 `mixer_analysis` 就是这么做的）。
   不要因为参数化**允许**长程就假定模型**用了**长程。
3. **先确认任务不依赖长程就无解**，再去评判算子的相互作用是否足够丰富。
   否则你会把"任务太简单"误读成"算子不够强"。
